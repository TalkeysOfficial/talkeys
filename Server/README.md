# Talkeys

## Setup

1. Go to project folder

> cd Talkeys

2. Install Dependencies

> bun install

3. Create .env with following content

````
DB_URL=

PORT=3000
SECRET=AAA
````

## Run

1. Start Server

> bun run start

2. Open in url or using an Endpoint tester (postman)

> http://127.0.0.1:3000/
